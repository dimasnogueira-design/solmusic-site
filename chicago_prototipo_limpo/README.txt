CHICAGO — PROTÓTIPO LIMPO

Este pacote foi reconstruído a partir do espelho local enviado pelo usuário.
Objetivo: servir como base visual/funcional de protótipo, sem depender do Shopify ou dos serviços da loja original.

ARQUIVOS
- index.html: página principal
- assets/style.css: estilos
- assets/app.js: galeria, quantidade, carrinho demonstrativo, abas e modal
- assets/img/: 8 imagens locais capturadas pelo HTTrack

O QUE FOI REMOVIDO
- analytics e pixels
- cookies/tracking
- Klaviyo
- Searchspring
- Yottaa
- checkout/Shop Pay
- scripts de conta/login
- widgets externos
- APIs e formulários da loja original

COMO ABRIR
1. Descompacte a pasta.
2. Abra index.html no navegador.
3. Para hospedar, envie todo o conteúdo desta pasta para o diretório público do hosting.

OBSERVAÇÕES
- Marca “SUA LOJA” é placeholder para não reutilizar a identidade visual da loja de referência.
- Preço exibido é apenas a referência presente na captura original e deve ser alterado.
- Carrinho e contato são demonstrativos; em Shopify, essas funções serão ligadas aos recursos nativos da plataforma.
